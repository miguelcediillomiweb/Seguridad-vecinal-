# Seguridad vecinal

Página web para que los vecinos envíen reportes de forma sencilla.

Incluye saludo y reloj dinámicos, reporte de emergencia, reporte normal, ubicación del teléfono, cámara/foto y guardado en Firestore.

La colección utilizada es `registros`.

**Pendiente antes de enviar datos reales:** colocar la configuración Web de Firebase en `app.js` y configurar las reglas de Firestore y Storage. Las notificaciones privadas a administradores/autorizados serán una etapa posterior y no se simulan como terminadas.
